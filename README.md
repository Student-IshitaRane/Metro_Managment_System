## Overview
The **Metro Management System** is a full-stack web application designed to automate and manage metro rail operations efficiently. It streamlines critical operations such as route management, station details, fare calculation, passenger records, and ticket booking. This system is built to enhance operational efficiency, improve passenger experience, and support real-world metro system management.

---

## Features
- **Route Management**: Add, update, and view metro routes.
- **Station Details**: Maintain information about all metro stations.
- **Fare Calculation**: Automatic fare calculation based on routes and distance.
- **Passenger Records**: Store and manage passenger information securely.
- **Ticket Booking**: Online ticket booking with record management.

---

## Technology Stack
- **Frontend**: HTML, CSS, JavaScript – for a responsive and interactive user interface.
- **Backend**: Node.js, Express.js – for efficient server-side operations and API handling.
- **Database**: MySQL – for secure and organized data storage.
- **Tools**: Postman (for API testing), VS Code (for development).
